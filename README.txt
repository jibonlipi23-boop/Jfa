পারিবারিক হিসাব Web App

GitHub Pages:
1. index.html, manifest.json, sw.js একই রিপোজিটরিতে রাখুন।
2. Settings > Pages > Deploy from branch নির্বাচন করুন।
3. Branch: main এবং folder: /root নির্বাচন করে Save করুন।
4. Pages-এর URL ফোনে Chrome দিয়ে খুলুন।
5. আগে Web App-এর সব ফিচার পরীক্ষা করুন।
6. তারপর APK বানানোর কাজ করুন।

ডাটা Local Storage-এ থাকে। Report থেকে JSON Backup/Restore করা যায়।
